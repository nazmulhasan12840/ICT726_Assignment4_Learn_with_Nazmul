# SEO keyword research and implementation

## Primary keywords
- online learning platform
- online courses
- web development course
- cyber security course
- data analytics course

## Supporting keywords
- artificial intelligence course
- digital skills course
- academic skills course
- beginner online courses
- flexible digital learning

## On-page implementation
- Descriptive `<title>` and meta description on every PHP page.
- Semantic `<h1>`, `<h2>` and `<h3>` hierarchy.
- Descriptive image `alt` text.
- Human-readable course titles and descriptions generated from MySQL.
- Canonical link tags.
- `robots.txt` and `sitemap.xml`.
- JSON-LD `EducationalOrganization` structured data on the home page.
- Internal links between home, courses, course details, registration and dashboard.
